# 병영 목록용 초상화 시안

기존 `assets/generals-v2/*-front.png` 독립 정면 원화를 그대로 사용한다. 별도 그림을 생성하거나 원본 파일을 수정하지 않고 4:5 표시 창에서 얼굴·상반신을 표현한다. 배경은 투명하여 공용 카드 바탕과 selected 색상이 그대로 보인다.

상단 6개 큰 카드는 **목록용 초상화 확대 비교**이며 병영 상세 영역을 바꾸는 제안이 아니다. 실제 병영의 선택 장수 상세는 기존 전신과 기마 100%·허저 85%·제갈량/초선/조조 70%, 발 기준점, 무기·말 다리 전체 외곽을 유지한다. 하단 선택 목록만 초상화를 사용한다는 표시 원칙은 사용자 지정이다.

초상화는 얼굴 폭과 눈높이를 맞춘다. 선택 전환 시 크기·위치를 바꾸지 않는다. 구체적인 크롭은 시안 검토 대기이며 실제 병영 코드는 아직 변경하지 않았다. 사용자 저장에도 접근하지 않는다.

검수: 로컬 8780 서버 실행 후 `node game/previews/portraits-v1/review.cjs`. 6개 원본 해시, 12개 창의 종횡비·눈높이·얼굴 폭, 선택 전환, 941/390/320 화면과 저장소 미사용을 확인한다.

후속 확정: 2026-11-14 사용자가 본 시안을 승인하여 실제 병영 하단 선택 목록에 적용했다. 위 검토/적용 대기 표기는 이 기록으로 대체한다. 좌표와 렌더링은 공용 general-portraits.js/css를 사용한다. 실제 사용자 클릭 검수는 대기다.
