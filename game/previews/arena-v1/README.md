# 군웅대전 시안 v1

사용자 확정 완료. 실제 게임은 `arena-ui.js`로 적용했으며 상대 선택·대전 시작·보상에 연결했다. 이 디렉터리는 최초 확정 시안으로 유지한다. 수치·진영·편성은 예시이며 이 미리보기는 저장이나 거래를 수행하지 않는다. 실제 화면에서는 이후 사용자가 요청한 기마/보행 크기 보정도 적용한다.

- 상하단은 `artworkShell`로 기존 프레임·재화·하단 탭 자산을 그대로 사용한다.
- 가변 버튼 9개, 패널 3개는 `nineSlice`로 구성한다. 941px 기준 28px 모서리를 유지하고 크기를 바꿀 때 pressed 알파도 함께 생성한다. 작은 버튼도 모서리 2개보다 여유 있는 높이를 사용한다.
- 관우·여포의 대표 장면과 하단 6장수는 `generals-v2`의 기존 독립 정면 원화다. 이미지 재생성, 누끼, 무기·발끝 자르기 없이 원본 비율로 배치한다.
- `courtyard.png`만 built-in image_gen으로 새로 생성했다. 생성 출처와 전체 프롬프트는 `design-delivery/v2/05-mockups/arena-versus-v1-generation.json`에 있다.
- 실제 규칙의 훈련 10·각성 3·보물 미적용, 승리 20골드·군공 10, 일일 보상 10회, 하루 3판 보상 다이아 10을 안내한다. 실제 화면의 상세 규칙·금지 장수·상대 상세는 대전 규칙에, 방어 편성은 편성 변경 메뉴에 연결되어 있다.
