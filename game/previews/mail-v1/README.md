# 우편함 — 시안 확정 / 실제 게임 적용

2026-11-14 사용자가 상세 버튼 여백을 포함한 시안을 확정했다. `http://127.0.0.1:8780/game/previews/mail-v1/index.html`은 디자인 기준과 메모리 예시를 유지한다. 실제 게임은 성문의 ‘우편’ 또는 `#mail`로 연다. 실제 사용자 클릭 검수는 대기 중이다.

- 기준 이미지: `design-delivery/v2/05-mockups/mail-v1.png`, `mail-v1-mobile.png`.
- 공용 `ui-shell`, `art-controls`, `art-layout`, `nine-slice` 및 승인된 코인/다이아 원본을 재사용한다. 신규 그림/누끼/임의 crop은 없다.
- 본문 x=20~921, 하단 버튼 끝 y=1478와 공용 하단 시작 y=1498 사이 20px, 안내 문구 앞뒤 12px를 유지한다.
- 사용자 추가 요청으로 상세 내부 ‘우편 삭제/보상 받기’도 위쪽 보상 표시와 아래쪽 패널에서 각각 20px를 띄웠다. 버튼 y=1276~1340, 패널 끝 y=1360이다. 버튼 높이와 상하 기준선이 같다.
- 선택은 같은 크기의 프레임 색상만 바꾼다. 나인슬라이스 모서리 28px를 고정하며 pressed는 완성 자산 alpha를 사용한다.

예시는 기존 `questDefs`/`periodBonus`의 보상과 우편 필드를 사용한다. 수령 가능 2통, 수령 완료 1통, 기한 만료 1통으로 상태를 구분한다. 만료/기수령 우편은 다시 받을 수 없고 모두 받기는 유효한 미수령 우편에만 적용한다. `serviceCommand`는 메모리 예시에만 실행하며 새로고침하면 초기화된다. 실제 저장에는 접근하지 않는다. 삭제 버튼은 실제 적용 시 확인 창이 필요하다는 시안 안내만 보여주며 예시 우편을 제거하지 않는다.

검수: `node game/previews/mail-v1/review.cjs`. 공용 상하단 224,470픽셀, 51개 활성 버튼 상태의 pressed 외곽/테두리, 16종 나인슬라이스, 3개 탭×3개 화면 크기, 좌우/상하 간격, 선택 크기 유지, 만료/빈 목록/수령/모두 받기/초기화, localStorage와 IndexedDB 미사용을 확인한다. 결과는 `qa.json`과 `test-artifacts/mail-v1/`에 기록한다.

실제 구현: `mail.js`는 저장 거래/삭제 확인/기간 갱신/이동, `mail-model.js`는 실제 우편 필터/3통 페이지/선택/합계, `mail-ui.js/css`와 `mail-ui-template.js`는 공용 자산 렌더를 맡는다. 개별 수령과 삭제는 저장 성공 뒤 표시를 갱신한다. 모두 받기는 기존 방식대로 우편별 거래를 순차 실행하고 실패한 우편을 남긴다. 삭제는 공용 확인 창에 제목·미수령 보상 손실 여부를 표시한다. 조회/선택/탭 전환은 저장을 변경하지 않는다. 다른 보상 재료는 목록에서 종류 수, 상세에서 전체 내역을 확인할 수 있으며 긴 본문/첨부 내역은 프레임 안에서 스크롤한다. 실제 검수는 `node game/tests/run-browser.cjs mail-ui mail-flow`이다. 사용자 저장 대신 격리 프로필을 사용한다.
