# 장수 도감 시안

상태: 사용자 검토 대기. 실제 병영의 등용 장수 전용 목록 수정은 적용했지만 도감은 독립 시안이다.

공용 상하단/버튼, general-portraits.js의 승인 투명 초상화, general-art.js의 전신/체격, collection.js의 실제 등용처·세력 수집 보상 정의를 재사용한다. 기본 49장수 6명씩 페이지, 세력별 필터와 선택 상세를 제공한다. 보유 3명/재화는 메모리 예시이며 저장소에 접근하지 않는다.

본문 x20~921, 하단 버튼 top/bottom 각20, 확장 프레임의 28px 고정 모서리와 최종 alpha를 사용한다. 신규 bitmap/누끼 생성은 없다.

검수: node game/previews/codex-v1/review.cjs (8780 로컬 서버 필요).
