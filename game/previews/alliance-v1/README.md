# 동맹 본부 시안 v1

사용자 확정 완료. 실제 게임은 `game/alliance-ui.js`에 동일한 본부 배치를 적용했으며 출석·기부·군량 지원은 기존 저장 트랜잭션에 연결했다. 이 디렉터리는 재현 가능한 시안으로 유지한다.

- 공용 `artworkShell` 및 `art-controls`로 확정된 상하단과 normal/selected/pressed를 그대로 사용한다.
- 늘어나는 10개 버튼과 2개 패널은 실제 `nineSlice` 렌더러로 구성한다. 모서리는 기준 화면에서 28px 고정이며 아이콘·글자는 별도 DOM이다.
- 동맹 배경만 새로 생성했다. 관우·제갈량은 기존 독립 정면 원화를 완전한 크기로 배치했다.
- 청운동맹 12명, 공헌 120, 준비도 60%, 상단 재화는 검토용 예시다. 동작 안내 문구는 현재 동맹 규칙을 따른다. 모든 버튼은 시안 안내만 표시하며 사용자 저장소·거래에는 접근하지 않는다.
- 실제 화면의 미가입 상태는 검색/창설 버튼을 표시한다. 동맹원·활동 기록·관리·토벌 상세는 기존 대화상자 기능에 연결되어 있다.

실행: `/game/previews/alliance-v1/index.html`
검수: `node game/previews/alliance-v1/review.cjs`

검수는 이 시안의 PNG를 다시 저장한다. 확정된 다른 화면 PNG는 덮어쓰지 않는다. 공통 상하단 224,470픽셀 일치, 18개 버튼의 전체 테두리 pressed와 투명 외곽, 14개 나인슬라이스 크기의 모서리 일치, 3개 화면 크기에서 원화·글자 영역을 확인한다. 생성 프롬프트와 출처는 `design-delivery/v2/05-mockups/alliance-headquarters-v1-generation.json`에 있다.
