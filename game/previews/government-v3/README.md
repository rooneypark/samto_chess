# 내정 마을 재설계 · 검토 중

v1 텍스트 카드와 v2 독립 건물 합성안은 대체 대상이다. 사용자는 마을 전체를 먼저 함께 그려 시점·규모·길·그림자를 맞추고, 확정 후 시설을 분리하거나 동일한 독립 원화로 재제작하도록 요청했다.

현재 town-zoned.png는 built-in image_gen으로 그린 전체 원화이며 아직 승인되지 않았다. 넓은 중심 도로와 횡단 도로, 농업/군영/공방/상업 구역을 구분한다. 주요 시설은 큰길 앞에 배치하고 관련 부속 시설을 뒤에 둔다. 상업 구역은 기존 장터와 주변 주막/상점이며 게임 시설을 주막으로 변경한 것은 아니다. 색수와 세부 묘사를 줄인 픽셀 표현을 사용한다.

공용 UI 및 실제 저장 변경 없음. 이전 government-v2 미리보기는 최신 원화가 아니며 재사용/확정하지 않는다. 최종 프롬프트는 prompt.txt에 기록한다.

사용자가 마을 원화 방향을 수용하고 클릭 가능한 UI 적용 요청. v3 index.html에서 통합 마을 원화 위에 투명 건물 선택 영역과 작은 공용 이름 버튼을 배치했다. 선택/pressed는 이름표에서만 표현하며 원화에 사각형 마스크를 씌우거나 건물을 잘라내지 않는다. 병영 이름표가 주막 지붕을 가리는 지적을 반영해 큰길 방향으로 옮기고 4종 이름표를 140×44, 모서리18 규격으로 줄였다. 상세/수령/강화는 아직 메모리 시안이고 실제 게임 데이터 적용은 하지 않았다.

검수 통과: 공용 상하단224470픽셀 동일, 63개 pressed, 14종 기본 프레임 및 2색 작은 이름표 모서리18 일치. 건물 눌림 중 마을 원화 픽셀 불변/이름표 반응, 선택 크기 고정, 4시설×3화면 크기 정렬/텍스트/상하 여백 및 메모리 수령/강화/초기화 확인. 390px 화면에서 주막 지붕 가림 해소 직접 확인.

사용자 지정 구역 pressed: districts.js의 농업/군영/공방/상업 영역을 SVG path hit shape와 동일한 alpha 마스크로 사용한다. 원화는 변경/누끼하지 않고 해당 구역 위에 공용 art-controls의 .28 어두움만 표시한다. 이름표도 함께 반응. 공용 입력은 data-art-hit-shape=path일 때만 elementFromPoint로 경계 이탈을 판정해 취소하며 기존 사각형 버튼 동작은 유지한다. district-review.cjs에서 4구역 선택/pressed/해제/이탈취소/큰길 픽셀불변/390px 확인.
