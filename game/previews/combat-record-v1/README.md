아군/적군 및 피해량/치유량/전법 횟수 탭, 지표별 정렬, 장수 선택과 상세 수치를 눌러볼 수 있다. selected는 같은 크기의 프레임 색만 바꾸며 pressed는 실제 알파를 사용한다. 주요 패널과 버튼 묶음은 x=20~921, 버튼 사이 18px로 맞췄다.
