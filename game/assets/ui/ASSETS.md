# 삼국체스 공통 UI 에셋

제작 방식: built-in imagegen. 기준 이미지: docs/ui/lobby-approved.png.
생성 원본을 그대로 보관하고, 코드에서 크기와 atlas 위치를 지정한다. 모든 글자와 재화 수치는 HTML로 표시한다.

## 생성 프롬프트 요약
- gate-background.png: 승인된 성문 시안의 구도와 청회색/청록 픽셀 스타일 유지. 삼국지 성문, 계단, 깃발, 석재 마당. UI, 글자, 장수 모두 제거한 세로 배경.
- button-primary.png: 같은 스타일의 가로 3:1 청록 버튼. 계단형 픽셀 테두리, 간결한 모서리 장식. 글자와 아이콘 없이 투명 외곽.
- panel.png: 같은 스타일의 정사각 남청색 패널. 확장 가능한 직선 테두리와 단순한 모서리, 비어 있는 중앙, 투명 외곽.
- icons.png: 같은 스타일의 투명 배경 4열 3행 아이콘 atlas. 1행 상점/투구/성문/동맹 깃발, 2행 교차 검/우편/임무 두루마리/설정, 3행 지도/골드/다이아/보물 상자. 글자 없음.

## 구현
- game/index.html: 성문 대기화면
- game/style.css: 픽셀 확대 및 패널/버튼 적용, atlas 위치 정의
- game/heroes.js: 촉한유비전 원본 장수 출처와 이미지 경로
- Neo둥근모 폰트: neodgm.woff2, 라이선스 FONT-LICENSE.txt

상점·병영·동맹·군웅대전 탭과 실제 전투·성장·재화 저장이 연결되어 있다. 세부 구현 상태와 제약은 docs/v012-implementation-audit.html을 참고한다.

## 현재 선택/눌림 상태
- panel.png의 동일한 테두리와 픽셀 질감을 공통으로 사용한다.
- 선택 상태는 청록 강조, 눌림 상태는 CSS 내부 음영과 내용의 1px 이동으로 표현한다.
- 별도 menu-pressed 이미지는 현재 실행 경로에서 사용하지 않는다.
