# 상점 구현 계약

- 기획 근거: docs/삼국체스_최종기획결정_개발전달_v1.0.txt, 상점 시안 docs/ui/shop-concept-v1.png.
- 신규 프로필: 500골드, 무료/유료 다이아 0, 조운/유비/황충/의용보병/의용궁병/군영참모, 빈 보물함. 기존 저장은 재화/성장/편성을 보존해 v3로 이관한다.
- 현재 장수 풀 14종: 초선 원본 연결 미확인으로 제외. C/B/A/S 확률은 60/30/8/2 유지, 등급 내 균등. 12종 보물 풀은 별도 천장.
- 모집 단가: 300골드 또는 100다이아. 10회 할인 없음. 무료 다이아 우선 사용. A/S 천장 30/100, S 우선, 10회도 개별 처리.
- 장수 최초 획득은 해금, 중복은 각성 카드, 최대성 중복은 C/B/A/S별 장수재료 1/2/4/8. 보물은 각각 별도 인스턴스.
- 상품: 무료다이아100→골드300(일3회), 장수재료20→A장수 선택(주1회), 보물재료20→A보물 선택(주1회). 선택과 지급은 동일 transaction. 한국시간 05:00, 주간 월요일 갱신.
- 저장: 비용/보상/천장/한도/명령 영수증/미확인 결과를 단일 IndexedDB 거래로 반영 (localStorage는 호환 미러). commandId 재전송은 이중 차감 없음. 모집 seed와 결과를 기록한다. 결과 확인은 재지급하지 않는다.
- 현재 브라우저 저장 기반 게임이다. 인증/결제/서버 권위 시각은 미구현이며 기기 시계 조작을 완전히 막지는 못한다. 시간 역행 시 이전 기간으로 한도를 되돌리지는 않는다. 공통 저장 계층에서 요청을 직렬화하고 IndexedDB revision 검사로 오래된 저장 버전의 덮어쓰기를 거절한다.
- 획득 장수는 병영/세력필터/성장/6인 편성 교체/성문에 반영. 보물은 보물함/장착/능력치에 반영. 전투 능력치와 결과 보상까지 연결되어 있다.
- 이미지 근거: heroes.js에 원본 HeroData 번호와 unit/pose를 기록. 신규 C지원병은 원본의 보병/궁병/책사 클래스 그래픽을 새 게임의 지원병에 연결한 것. 원작에 동일 이름의 인물이 있었다는 의미가 아니다. STATIC_VERIFIED는 테이블→파일 연결과 화면 확인을 뜻하며 애니메이션 전체 검증을 뜻하지 않는다.
