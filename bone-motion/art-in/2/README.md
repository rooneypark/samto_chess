- `side.png`: 왼쪽 측면

## 모션 작업 순서

1. 세 방향을 공통 축척의 256×256 투명 원화로 준비하고 실제 치수를 검수한다. 방향마다 개별 contain-fit하지 않는다.
2. 기본 자세 원화의 실제 관절과 무기 끝을 새로 측정한다.
3. 기본 자세 원화와 확정 본으로 대기모션을 생성한다. GUARD는 임의 변경하지 않는다.
4. 대기모션 중 방향별 기준 프레임 1장을 선정하고 해당 프레임의 본 좌표를 연결한다.
5. 선정한 대기 이미지를 공격·스킬 모션의 시작 이미지로 사용한다. 그립·관통·접지·대기 복귀를 전 프레임 확인한다.

목표 치수: 보병 신체 키124px, 폭115%, 접지(128,224), 표시1.00, 장팔사모 전체140px·날36px. 머리와 몸 전체를 일괄 확대하지 않는다. 이 수치는 생성 목표이며 현재 그림의 실측값이 아니다.
