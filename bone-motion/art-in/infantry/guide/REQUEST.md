# 의용보병 전투 대기 원화 요청 (ID `infantry`, 창·방패)

정면, 왼쪽 측면, 후면 3장을 그린다. **납품은 256×256 PNG다.**

- `guide-front.png`, `guide-side.png`, `guide-back.png`: 보기 편하게 4배(1024×1024)로 키운 안내 그림이다. 글자와 치수를 읽는 용도이고, 이 크기로 그리지 않는다.
- `guide-front-256.png`, `guide-side-256.png`, `guide-back-256.png`: 같은 안내를 실제 크기(256×256)로 그린 것이다. 이 그림을 밑에 깔고 그 위에 그린다. 좌표가 납품 그림과 1:1로 맞는다.
- 큰 캔버스에서 그린다면 정확히 4배(1024×1024)로 그리고 4×4 픽셀 블록 단위로 찍은 뒤, 마지막에 최근접(nearest) 방식으로 256×256으로 줄인다. 다른 배율이나 부드러운 축소는 쓰지 않는다.

## 이 장수의 특징

- **살릴 것:** 일반 병사. 창과 둥근 방패.
- **인물과 외형(통합가이드 12절):** 일반 병사의 정직한 창·방패 동작. 영웅처럼 큰 도약이나 위압을 넣지 않는다.

## 크기

| 항목 | 값 | 표준과의 차이 |
|---|---|---|
| 키 | 표준 본의 100% | 표준 |
| 어깨·몸통·팔다리 폭 | 표준의 100% | 표준 |
| 창 전체 길이 | **104px** | 표준 (이 유형의 한계 120px) |
| 날·머리 부분 | 20px | 전체 길이 안에서 차지하는 길이 |

몸을 줄이거나 키워서 무기 비율을 맞추지 않는다. 몸과 무기는 각각 위 값으로 그린다.

## 방향별 좌표 (256×256 캔버스)

| 방향 | 머리 꼭대기 y | 오른손 | 왼손 | 무기 (끝 → 무기 끝) |
|---|---|---|---|---|
| 정면 | 112 | (100, 176) | (138, 174) | (102, 210) → (97, 122) |
| 왼쪽 측면 | 109 | (123, 166) | (106, 170) | (133, 203) → (108, 106) |
| 후면 | 108 | (156, 173) | (118, 160) | (154, 213) → (159, 109) |

### 무기와 몸의 앞뒤

가이드 그림에서 빨간 실선은 무기가 몸 앞에 있거나 몸과 겹치지 않는 부분이고, 보라 점선은 몸 뒤로 지나가 가려지는 부분이다. 3D 본에서 계산한 것이다.

- 정면: 몸과 겹치지 않는다
- 왼쪽 측면: 끝에서 0~11% 구간은 오른 허벅지의 뒤(몸에 가려진다); 끝에서 11~57% 구간은 몸통의 뒤(몸에 가려진다); 끝에서 61~93% 구간은 머리의 뒤(몸에 가려진다)
- 후면: 몸과 겹치지 않는다

### 몸의 앞뒤 (겹치는 부분을 어떻게 그리나)

같은 자세를 방향마다 다르게 보기 때문에, 방향에 따라 앞에 오는 팔다리가 달라진다. 아래는 3D 본에서 계산한 것이다. "앞"은 카메라에 가까워 위에 덮어 그리는 쪽, "뒤"는 가려지는 쪽이다.

**정면** (캐릭터가 화면 쪽을 본다)

- 그리는 순서(먼 것부터 가까운 것): 오른 위팔 → 오른 정강이 → 오른 아래팔 → 오른 허벅지 → 몸통 → 머리 → 왼 허벅지 → 왼 위팔 → 왼 정강이 → 왼 아래팔
- 왼 허벅지: 몸통 앞에 그린다
- 오른 허벅지: 몸통 뒤로 가려진다

**왼쪽 측면** (캐릭터가 화면 왼쪽을 본다)

- 그리는 순서(먼 것부터 가까운 것): 오른 아래팔 → 오른 위팔 → 오른 허벅지 → 오른 정강이 → 머리 → 몸통 → 왼 정강이 → 왼 허벅지 → 왼 위팔 → 왼 아래팔
- 왼 위팔: 몸통 앞에 그린다
- 왼 아래팔: 몸통 앞에 그린다
- 왼 허벅지: 몸통 앞에 그린다
- 오른 아래팔: 몸통 뒤로 가려진다
- 오른 허벅지: 몸통 뒤로 가려진다

**후면** (캐릭터가 화면 안쪽을 본다)

- 그리는 순서(먼 것부터 가까운 것): 왼 아래팔 → 왼 정강이 → 왼 위팔 → 왼 허벅지 → 머리 → 몸통 → 오른 허벅지 → 오른 아래팔 → 오른 정강이 → 오른 위팔
- 왼 허벅지: 몸통 뒤로 가려진다
- 오른 허벅지: 몸통 앞에 그린다

- 왼쪽·오른쪽은 항상 **캐릭터 자신의** 왼쪽·오른쪽이다. 정면 그림에서는 캐릭터의 왼쪽이 화면 오른쪽에 온다. 가이드 인형은 왼쪽 팔다리가 하늘색, 오른쪽이 분홍색이다.
- 가려지는 부분은 그리지 않는다. 가려진 손이나 무기를 보이게 하려고 위치를 옮기지 않는다.

- 발바닥은 세 장 모두 y=224 선 위. 접지 기준점은 (128, 224). 정면과 후면에서는 카메라에 가까운 발이 조금 더 아래에 그려진다.
- 무기 길이는 측면 그림에서 잰다. 정면과 후면에서는 무기가 기운 만큼 조금 짧게 보일 수 있다.
- 정면과 후면에서는 카메라에 가까운 발이 더 아래에 그려진다(앞뒤로 벌린 자세를 위에서 비스듬히 본 것이다). 무릎을 굽힌 자세라 다리가 짧아 보이고 앞다리가 뒷다리를 가린다. 인형의 겹침 순서를 따른다.
- 손이 가려지는 방향에서는 손을 억지로 보이게 하지 않는다. 무기와 몸의 앞뒤만 맞춘다.

## 지킬 것

1. 최종 파일은 256×256 PNG, 투명 배경. 1024로 그렸다면 반드시 256으로 줄여서 넘긴다. 바닥·그림자·배경 없음. 캐릭터 바깥에 희미한 픽셀이 남지 않게 한다.
2. 세 장은 같은 자세를 세 방향에서 본 것이다. 목과 골반의 높이가 세 장에서 같아야 한다.
3. 손이 무기를 잡는 자리, 두 발의 자리, 몸의 방향은 가이드와 같게 한다.
4. 가이드의 선, 점, 글자, 회색 인형, 격자는 그리지 않는다.
5. 얼굴, 수염, 머리 장식, 복색, 갑옷, 무기의 모양은 이 장수답게 그린다. 그림체는 승인된 픽셀 그림체(굵은 외곽선, 큰 색면)를 따른다.

## 넘기기 전에 스스로 잴 것

- 측면 그림에서 무기의 양 끝 사이 거리가 99~109px인가.
- 파일 크기가 256×256인가(1024×1024가 아닌가).
- 측면 그림에서 머리 꼭대기(상투·투구 제외)가 y=109 근처(±4)이고 발바닥이 y=224인가.
- 캔버스 가장자리 3px 안에 닿는 픽셀이 없는가.
- 세 장의 축척이 같은가(따로 확대·축소하지 않았는가).
