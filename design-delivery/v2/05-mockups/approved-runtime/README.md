# 사용자 확정 런타임 기준

2026-11-13 사용자가 현재 작업을 확정한 직후, 리팩토링 전에 캡처했다. 성문·병영·상점·출정 × 941/390px의 8개 실제 게임 화면이다.

`game/tests/approved-ui-browser.cjs`에 재현 가능한 격리 테스트 상태가 정의되어 있다. 6장수, 12,450 골드·320 다이아, 군주 Lv.20 등은 비교용 브라우저에만 설정한다. 실제 사용자 프로필은 변경하지 않는다.

일반 실행은 기준을 읽기만 한다. `--record`로 기준을 갱신하려면 변경된 화면을 사용자에게 먼저 확정받아야 한다. 원본 시안 PNG는 별도로 보존한다.

2026-11-14 사용자가 병영에도 이미 확정한 기마 100%/허저 85%/제갈량·초선·조조 70%를 적용하도록 지적하여 병영 941/390px의 원화 영역만 갱신했다. `--record-barracks-scale`은 이 체격 보정 전용이며 원화 슬롯 밖에 변경이 있으면 거부한다. 두 화면에서 각각 127,840/20,774픽셀만 바뀌었고 UI 프레임·글자·버튼 등 원화 자리 밖은 동일하다. 전체 8장 기준을 무조건 다시 기록하지 않는다.
