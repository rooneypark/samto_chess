# 전투지 지도 원화 가이드

2026-11-13 사용자 최종 수정. 이후 추가할 전투지에도 적용한다.

- 기존 게임의 픽셀 그림체를 유지하되 작은 기호형 건물로 간결하게 그린다. 상세 건축 일러스트, 많은 소품, 바위·수풀·넓은 지형 받침을 피한다.
- 같은 장의 1·2·3 전투는 **동일한 이미지**를 사용한다. 1장 황건 산채, 2장 사수관 성벽, 3장 호뢰관 관문으로 장 사이에서만 구분한다.
- 기존 `campaign-v2`의 전투마다 다른 크고 세밀한 원화는 사용자 폐기안이다. 재사용하지 않는다. 이전의 전투별 독립 그림 지침은 이 수정으로 대체한다.
- 전투 이름은 확정한 공용 파란색/녹색 프레임에 표시하고 나인슬라이스 모서리를 보존한다. 종이 띠 이름표로 바꾸지 않는다.
- 우선 3종 원화와 이름 프레임 시안을 검토받은 후 전체 지도 배치를 진행한다. `game/previews/campaign-v3/` 정상 원화 3종은 사용자 확정이며, 확정 전체 화면 기준은 `game/previews/campaign-v4/`이다.
- 클리어는 장별 공용 원화의 간결한 파괴 변형으로 표현한다. selected는 원화 크기·위치를 유지하면서 바닥 표시와 공용 이름 프레임을 강조한다. 잠김은 작은 자물쇠를 쓴다. 하단 상태 범례 없이 구분할 수 있어야 한다.
- 깃발·지붕·외곽을 자르지 않는다. 전체 화면에서 건물을 잘라 쓰지 않고 독립 투명 원화를 사용한다. 생성 시 남는 alpha=1 잔점만 정리하며 보이는 외곽과 안티앨리어싱을 보존한다.
- 입력은 `art-controls.js`를 재사용한다. 선택 전환 시 크기·배치를 유지하고 pressed는 실제 원본 alpha에 맞춘다.

이 기준은 게임 원화를 위한 표현 지침이며 새로운 스토리나 성장 규칙을 추가하지 않는다. 정상 원화 3종은 확정되었고, 장별 파괴 원화 3종과 잠금·선택 상태를 포함한 전체 지도도 사용자 확정되어 실제 게임 데이터에 연결했다. 런타임은 `campaign-ui.js`와 `campaign-landmarks.js`, 배포 원화는 `game/assets/campaign-v4/`다.
