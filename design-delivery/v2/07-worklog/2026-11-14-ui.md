# 2026-11-14 UI 구현·확정 기록

사용자 요청에 따라 정리한 다음 작업용 기록. 날짜는 현재 작업 환경의 한국 시간 기준이다. 이전 날짜에 확정한 화면을 오늘 새로 구현했다고 취급하지 않는다. 다음 작업 시작 시 루트 `AGENTS.md`와 이 문서, `06-components/README.md`를 함께 읽는다.

## 오늘 확정하고 구현한 화면

### 전역 선택

- 사용자가 전역 선택 구현을 직접 확인하고 최종 확정했다. `game/campaign.js`, `campaign-ui.js`, `campaign-ui-template.js`, `campaign-ui.css`, `campaign-landmarks.js`가 실제 화면이다.
- 기준은 `05-mockups/campaign-selection-v4.png`, 시안은 `game/previews/campaign-v4/`. 과거 v1은 대체된 시안이고, 크고 세밀한 v2 전투지 원화는 사용자 폐기안이다.
- 1장 황건 산채, 2장 사수관 성벽, 3장 호뢰관 관문을 사용한다. **같은 장의 세 전투는 같은 원화**, 클리어하면 같은 건물의 파괴 변형으로 표시한다. 후속 전투지를 추가할 때도 이 원칙을 유지한다.
- 전투 이름은 기존 이름 프레임에 넣는다. selected는 원화 크기·위치를 유지하며 금빛으로 표시하고 잠금은 작은 자물쇠로 표시한다.
- 실제 전투 선택 저장·출정·클리어·최초/반복 보상·잠금·어려움에 연결했다. 전체 전역·군략·훈련은 천하 평정 목록에서 접근한다. 전역에서 시작한 출정은 종료 후 전역으로 돌아온다.
- 출정 저장에 실패하면 전투 화면을 열지 않고 오류를 표시한다. 잠긴 전투를 눌러도 기존 선택 저장을 바꾸지 않는다.

### 전투 결과·보상

- 사용자가 `05-mockups/battle-results-v1.png`를 확정하고 실제 게임 적용을 요청했다. `game/results-ui.js`, `results-ui-template.js`, `results-ui.css`, `results-model.js`를 `battle.js`에 연결했다.
- 공용 상하단·두루마리·버튼·군웅대전 배경·독립 장수 원화·사수관 아이콘을 재사용했다. 새 이미지 생성이나 전체 시안의 장수 영역 누끼는 하지 않았다.
- 최종 승리: 실제 정산 영수증의 골드·다이아·재료·장수 합류를 표시한다. 최초 클리어는 실제 정산 시 기록한 `firstClear`로 구분한다. 예전 영수증에 이 정보가 없으면 일반 클리어로 표시한다.
- 중간 승리: 다음 라운드와 실제 준비 은화·장비 선택에 연결한다. 아직 지급하지 않은 라운드 보상을 ‘지급 완료’로 표시하지 않는다.
- 패배: 기존 최대 2회 재도전과 전투 직전 배치·은화·장비 복구를 사용한다. 소진 후 재도전 버튼을 제거한다.
- 군웅대전: 승리·패배·무승부와 실제 골드·군공·다이아·점수 영수증을 표시한다. 새로운 보상 규칙을 추가하지 않는다.
- 전투 기록, 전역/군웅대전 복귀, 성문 복귀, 하단 메뉴를 연결했다. 남은 라운드나 재도전을 버리는 이동은 게임 내 확인창을 거친다.
- 저장 실패는 저장 대기로 표시하며 재시도할 수 있다. 별도 ‘보상 받기’ 버튼으로 중복 정산하지 않는다. 재접속은 저장 영수증을 재사용한다.
- 기초 훈련의 단계별 안내와 classic 화면은 기존 진행 UI를 유지한다. 이 구현을 캐릭터 이동·공격 모션 완성으로 취급하지 않는다.

## 오늘 지정한 정렬과 기존 확정 기준

- **941×1672 캔버스에서 본문 왼쪽 x=20, 오른쪽 x=921, 폭 901.** 주요 패널·전폭 버튼·하단 분할 버튼 묶음의 양 끝을 일치시킨다.
- 결과 화면: 다음 전역과 전투 기록은 x=20/w=901. 하단 버튼은 왼쪽 x=20/w=582, 간격 18, 오른쪽 x=620/w=301. 내부 텍스트 패딩 때문에 바깥 정렬을 바꾸지 않는다.
- 상단은 941×150, 하단은 941×174 공용 프레임을 유지한다. 내용과 활성 탭만 바꾼다.
- selected는 상점 selected 틀 기준. normal/selected의 아이콘·글자·영역 크기는 동일하며 바탕과 윤곽만 바뀐다. pressed도 크기·위치를 움직이지 않는다.
- 빈 확장 프레임은 나인슬라이스 우선. 원본 분할 112px / 논리 모서리 28px를 유지하며 원화 문양을 임의로 자르거나 늘리지 않는다. 작은 배지는 논리 높이 64px 이상으로 양쪽 모서리를 보존한다.
- 누끼는 실제 원본 알파 외곽 기준. 외곽선·하이라이트·깃발·말 다리·무기 끝을 보존한다. 임의 다각형 clip-path는 금지한다.
- 관우·여포 기마 높이 기준 보행 장수 높이 70%, 발 기준선 통일. 장수는 원본 비율을 유지한 독립 스프라이트로 배치한다.

## 후속 수정 — 허저 체격

사용자가 제갈량·초선·조조의 크기는 맞지만 허저는 이들보다 크고 기마 관우·여포보다 작아야 한다고 지적했다. 공용 `character-scale.js`를 기마 100% / 허저 85% / 다른 보행 70%로 수정했다. 발 기준선과 원본 종횡비·무기 외곽을 유지한다. 전투 기록 시안, 군웅대전, 결과의 공용 원화 배치에 반영되며 기존 전투 능력치나 격자는 변경하지 않는다. 결과 기준 이미지는 이 체격 보정에 해당하는 허저 영역만 바뀌는지 대조 후 갱신한다.

허저 체격 수정 검수 완료: 전투 기록 시안 검수 및 결과/군웅대전 브라우저 검사 2/2 통과. 결과 기준 이미지의 변경 10,531픽셀은 허저 원화 영역 안에만 있고 다른 픽셀은 모두 동일했다. 기마 100% / 허저 85% / 조조 등 70% 비율과 전체 실루엣을 확인했다. 기준 이미지는 사용자 요청한 허저 체격 부분만 갱신했다.
