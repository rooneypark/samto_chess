# PixelLab 첫 모션 시험

- 오늘 확정한 조운 이동은 정면 3차와 왼쪽·후면의 가벼운 달리기다. 승인 프레임과 실제 방향별 PixelLab 요청은 `art-source/motions/v1/15/manifest.json`에 보존하고 통합가이드 5절에서 다음 기마 장수 제작의 기준으로 연결했다. 정면 3~6번의 미세한 눈·눈썹 변화는 확대 비교에서 확인했다. 게임 반영은 별도이며 8×8 격자 합성 미리보기까지 제작했다.
- 쓰러짐은 장수별 1클립을 세 방향에서 공유한다. 정면 숨쉬기는 장수 상세용 1클립이다. 필수 수량은 장수당 11클립이다.

- 사용자 Tier 2 결제 후 첫 생성 요청. API 인증 성공, 시작 5,000 gens → 종료 4,992 gens. 비밀 토큰은 파일/저장소에 저장하지 않았다.
- 조운(ID 15) pixel256-v1 정면 원화를 그대로 `/v2/animate-with-text-v3`에 입력. 대기 호흡, 고정 정면·제자리·말발 접지·장비 유지 요청. 마지막 프레임에도 같은 원화 입력.
- 요청 8프레임, 실제 응답 9장. 원본 응답과 전 프레임을 보존하며 임의로 누락하지 않았다. 재생 시간은 검토용 프레임당150ms이며 확정 타이밍이 아니다.
- 위치: `test-artifacts/pixellab-zhaoyun-idle-v1/`. request.json, job.json, response.json, usage.json, frames, qa-report.json, contact-sheet.png, preview.gif, index.html.
- 파일 검수: 전부256×256 RGBA, alpha>16 기준 가장자리 접촉0, 가시 최하단225 유지. 첫 프레임 파일 SHA가 원화와 일치.
- 전체 프레임 육안 비교: 중간 얼굴/투구·말 머리 윤곽 변화가 보인다. 전체 접지 최하단 유지가 개별 관절/pivot 완전 고정을 증명하지 않는다. 밝은/어두운/대조색 및 정상/느린 재생 검토 UI 제공. 사용자 재생 검수 대기.
- 첫 검토 시안이며 최종 납품/모션 합격/사용자 승인/게임 적용은 아니다. 최종 자산 팩으로 승격하지 않았다. 게임·저장·기존 자산은 변경하지 않았다.

## 눈 유지 수정
- 사용자 요청: 조운 대기는 눈을 계속 뜨고 나머지 움직임 유지. 앞으로 모든 PixelLab 제작에서 깜박임/윙크 금지.
- 수정본: test-artifacts/pixellab-zhaoyun-idle-open-eyes-v2/. 원본은 보존. 동일 머리 위치의 프레임4 열린 눈을 기준으로 프레임5의 우측 눈 영역만 교정(23픽셀). 다른 프레임 및 영역·전체 alpha·9프레임·150ms 재생 불변 검증. 추가 API 생성/차감 없음.
- 통합가이드5절에 공통 영문 요청문·확대 검수·최소 눈 교정 예외 반영. 수정본 사용자 검토 대기, 게임 미적용.

## 눈·눈썹 모양 고정 3차
- 사용자 요청에 따라 첫 원화의 양쪽 눈·눈썹 RGB를 각 프레임 머리 이동량(0,0,3,4,4,4,2,0,0px)에 맞춰 적용. test-artifacts/pixellab-zhaoyun-idle-fixed-face-v3/. 눈·눈썹 두 국소 영역 밖 RGB와 전체 alpha 불변, 9프레임/150ms 유지 검증. 확대 비교 확인, 사용자 검토 대기.
- 다음 제작부터 눈·눈썹·코·입 모양/얼굴 내 상대 위치 고정. 머리 자체 움직임은 유지. 공통 영문 프롬프트와 기존 입 열기 연기보다 최신 원칙 우선임을 통합가이드5절에 기록. 추가 API 비용 없음.

## 조운 정면 이동 첫 시험
- 사용자 정면 이동 요청. 현재 원화 + 무표정 고정 및 제자리 네 박자 보행 프롬프트로 v3 생성. test-artifacts/pixellab-zhaoyun-front-move-v1/. 요청8프레임/반환9장, 8gens 사용, 잔여4,984.
- 전체256 RGBA/가장자리 잘림0. 다리 교대 움직임은 있으나 중간 얼굴 변형과 가시 발끝 y234~239 확장 등 접지/주기 검수가 남음. 합격/최종 납품/게임 적용으로 표시하지 않음.
- 사용자가 촉한 MOV 참조 직접 활용 여부 질문. 이번 호출에는 촉한 프레임을 입력하지 않았고 담당자가 보고 동작을 텍스트로 설명했다. 다음 접근은 참조 포즈/스켈레톤 기반 방식 검토. 말+기수 자동 관절 추정 및 최신256 지원 API 적합성은 별도 시험 필요.
