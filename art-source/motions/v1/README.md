## 폴더 구성 (장비 제외 10명)

- `final/idle` 숨 쉬는 대기 4장(각 260ms), `final/move` 이동 14장, 평타 3개와 전법 1개는 각 15장. 방향은 `front`, `left`, `rear`이고 오른쪽은 왼쪽을 뒤집어 씁니다.
- `guard/<방향>.png`는 모든 클립의 시작 자세(전투 대기)입니다. 클립을 더 만들 때 `python -X utf8 bone-motion/engine/finalize_heroes.py --guards`로 `bone-motion/art-in/<id>/`에 되돌려 놓습니다.
- `manifest.json`에 평타 순서, 전법, 클립 목록, 상태가 있습니다.
- 이 폴더는 `bone-motion/engine/finalize_heroes.py`가 만듭니다. 손으로 고치지 않습니다.
