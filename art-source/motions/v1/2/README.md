# 장비(ID 2) 확정 모션

2026-11-17 사용자 확정: 기본 공격(허리 높이 찌르기), 걷기, 전법(장판의 함성) 각각 전면·왼쪽 측면·후면. 9클립 108프레임, 256×256 투명 PNG, 원본 출력 그대로. 게임 연결, 별도 스킬 이펙트, 대기·피격·쓰러짐은 이 묶음에 포함하지 않는다.

- [manifest.json](manifest.json)은 저장소 루트 기준 파일 경로, 해시, 프레임별 시간, 이벤트 인덱스(0부터), 기준점을 기록한다. 미리보기 GIF에 추가된 중립 원화는 12장 시퀀스에 포함하지 않는다.
- 기준점은 대부분 (128,224), 평타 측면 원본만 (168,224)이다. 측면 평타를 공통 기준점에 맞출 경우 X를 -40px 적용한다.
- rigs/에는 실제 요청에서 first_frame만 분리한 관절과 파라미터가 있다. 재현할 때 manifest에 적힌 PNG를 PNG/base64 first_frame으로 추가한다. 토큰은 파일이나 Git에 저장하지 않는다. 승인본은 불필요하게 재생성하지 않는다.
- 함성은 몸 기준 왼옆으로 한 번 디딘다. 왼쪽 측면에서 화면 왼쪽으로 전진시키지 않는다. 깊이와 가림으로 표현한다. 입 연출은 앞·옆의 발동에만 요청했고 실제 결과에서는 뚜렷하지 않았다. 후면에는 얼굴이 없다.
- 바이너리는 assets-v1 릴리스에 담긴다. 저장소 루트에서 python tools/asset_packs.py restore를 실행한다.
