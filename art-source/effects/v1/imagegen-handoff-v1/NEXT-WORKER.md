# 다음 작업자에게 전달할 문구

삼토체스 전투 이펙트 38종의 제작과 인게임 적용을 맡아줘. 이미 그린 4종은 바로 연결하고, 나머지 34종은 준비된 참고 원화로 PixelLab에서 제작한 뒤 게임에 연결해줘.

1. Git에서 인계 자료 받기

- 저장소 https://github.com/rooneypark/samto_chess
- main 브랜치의 인계 커밋은 2e5979a야. 작업 중인 변경이 있으면 보존하고, 이 커밋을 포함한 최신 main에서 시작해줘.
- 저장소 루트에서 `python tools/asset_packs.py restore`를 실행해. PNG는 GitHub의 assets-v1 릴리스에서 복원돼.
- 먼저 `bone-motion/EFFECT-GUIDE.md`와 `art-source/effects/v1/imagegen-handoff-v1/README.md`를 읽어줘. 같은 폴더의 `manifest.json`에 38종의 ID, 용도, 기준점, 목표 크기, 재생 시간이 정리돼 있어.

2. 완성 프레임이 있는 4종부터 적용

- `direct`인 jab(짧은 찌르기), cut(짧은 베기), thud(방패 치기), spark(명중 섬광)는 재생용 투명 PNG가 이미 있어.
- 인계 폴더의 `fx/<id>/01.png`부터 `03.png`까지 순서대로 재생해. 각 `anchor.json`의 canvas, anchor, frameDurationsMs를 사용하고, 프레임마다 투명 여백을 자르거나 다시 가운데 정렬하지 마.
- 공격의 실제 타격 시점에 맞춰 한 번만 재생해. jab은 시전자에서 대상 쪽으로, cut은 대상 가슴을 기준으로 맞춰줘. cut은 총 174ms이고 `cut-review.webp`로 속도를 비교할 수 있어.
- 시뮬레이터와 실제 게임의 렌더링 경로를 각각 확인해. 실제 전투에서도 보이는 것까지가 적용 범위야.

3. 나머지 34종은 PixelLab으로 제작

- `manifest.json`에서 `mode: reference`인 34종이 대상이야. 종류마다 `pixellab/<id>/reference.png`와 `prompt.txt`가 준비돼 있어. 128×128은 참고 이미지 크기이고, 게임에서 표시할 크기와 기준점은 종류별 manifest를 따라줘.
- PixelLab `/v2/vfx`에 해당 그림과 설명을 넣어줘. `sprite_frames`와 `sprite_fps`는 입력 애니메이션용 필드야. 이번 참고 그림은 정지 PNG 한 장이므로, 원하는 출력 장수·속도는 설명에 요청하고 결과 JSON의 frames, fps, anchor와 실제 재생으로 확인해줘.
- 먼저 bolt(번개)와 shield(보호막)로 서로 다른 동작을 검수한 다음 나머지 32종을 이어서 제작해. 제출할 때 견적과 작업 ID를 기록하고, 중단 후에는 기존 작업 상태부터 조회해서 같은 효과가 중복 과금되지 않게 해줘.
- 방향과 실루엣은 `art-source/effects/v1/reference/<id>.png`의 여섯 장면과 비교해. 번개는 착탄점, 보호막은 몸통을 감싸는 위치와 캐릭터 가시성, 투사체는 출발점과 도착점을 특히 확인해줘. 효과에 캐릭터나 배경이 섞인 결과는 수정해줘.

4. 게임 연결과 검수

- 38종 공용 세트를 장수들이 공유하게 하고, 장수별 효과 배정과 색상은 가이드의 장수 표를 따라줘. 이펙트 적용 과정에서 피해량·범위·판정 같은 전투 규칙은 변경하지 마.
- 기존 효과와 중복 재생되지 않는지, 모바일 전투판에서 무기와 얼굴을 과하게 가리지 않는지, 일시정지·배속·이펙트 줄이기 설정이 동작하는지 확인해줘.
- 마지막에는 38종 각각의 제작·게임 연결·검수 상태와 남은 문제를 정리하고, 실제 모바일 전투에서 재생한 프리뷰를 보여줘. 생성, 적용, 사용자 최종 승인은 구분해서 기록해줘.
