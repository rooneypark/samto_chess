# Gemini 인계 프롬프트 — 기본 병종 5종

## 기준 원화

같은 폴더의 `index.html`에서 승인된 픽셀 원화 3방향을 확인한다. 신규 병종을 기존 게임 그림체에 맞추는 스타일 기준이며, 인물의 얼굴·복식·장비를 복사하지 않는다.

- 검병: `art-source/characters/v1/liaohua/{front,side,back}.png` — 간결한 한손검 병사
- 창병: `art-source/characters/v1/2/{front,side,back}.png` — 보행 창의 길이와 그립
- 방패병: `art-source/characters/v1/caohong/{front,side,back}.png` — 창·방패의 손 위치와 가림
- 궁병: `art-source/characters/v1/archer/{front,side,back}.png` — 활과 화살통
- 책사: `art-source/characters/v1/tactician/{front,side,back}.png` — 책사 비율과 소품 절제

## 복사해서 전달할 요청

삼국체스 모바일 전략 게임의 **기본 병종 원화 5종**을 제작해 주세요. 첨부한 `index.html`과 그 안의 원본 PNG들은 완성된 게임 원화의 그림체·외곽선 굵기·색면·명암·픽셀 밀도를 보여 주는 기준입니다. 원본 장수의 디자인을 베끼지 말고, 같은 게임에 들어갈 새 일반 병사를 디자인해 주세요.

대상은 **검병, 창병, 방패병, 궁병, 책사**입니다. 각 병종은 정면, 왼쪽 측면, 후면 3방향으로 그려 총 15개의 개별 PNG를 납품해 주세요. 5×3 합성 시트가 아니라 파일당 캐릭터 하나인 독립 이미지로 주세요. 각 병종의 세 방향은 동일 인물·복장·장비·체격을 유지하고, 같은 중립 전투 대기 자세를 카메라 방향만 바꿔 표현해야 합니다.

### 캔버스와 정합

- 파일 하나마다 정확히 256×256px, 8-bit RGBA PNG. 배경은 alpha=0으로 완전 투명
- 발 접지 기준 `(128,224)`, 공통 표시 배율 1.00. 세 방향 모두 캔버스 원점을 바꾸거나 캐릭터를 따로 확대/축소하지 않기
- 보병 본의 평균 체격을 따르며 책사는 더 작게: 보병 몸 기준 키 약 124px, 책사 약 111px. 머리·몸통 비율은 참고 원화의 공통 비율을 따르기
- 정수 픽셀 단위로 색을 끊어 표현하고, 안티앨리어싱·블러·서브픽셀 위치·자동 윤곽 보정은 금지. 확대/축소할 때는 nearest-neighbor만 사용
- 세 방향에서 발 위치, 몸통 폭·키, 머리 크기, 손 위치와 장비 크기를 동일하게 유지
- 무기와 장식은 캔버스 안에 온전히 들어오게 하고, 프레임 가장자리에서 자르지 않기
- 정면(front), 인물 기준 왼쪽 측면(side), 후면(back). 오른쪽 측면은 만들지 않기

### 장비 규격

- 검병: 한손 검 40px, 오른손 그립. 작은 장식과 문양은 최소화
- 창병: 보행 창 128px, 오른손 34px / 왼손 62px 지점 그립
- 방패병: 창 104px, 방패 지름 24px, 창은 오른손·방패는 왼팔
- 궁병: 활 68px, 왼손으로 활 가운데를 잡고 화살통을 멘다
- 책사: 부채 24px를 오른손에 들고, 무기 대신 책사 실루엣을 살린다

### 그림체와 납품

- 승인 원화처럼 굵고 깨끗한 외곽선, 읽히는 큰 색면과 단순한 명암으로 그린다.
- 복잡한 반복 문양, 가는 금선, 잔머리 선, 과한 점 장식, 발밑 그림자, 광채, 배경, 글자, 프레임, 워터마크는 넣지 않는다.
- 다섯 병종은 무기 실루엣만으로 구분되게 한다. 기존 참고 원화처럼 짙은 남색 외곽선, 큰 색면, 절제된 하이라이트를 공유하되 병종별 옷 색은 구분하고 전원을 똑같은 복제로 만들지 않는다.
- 출력 경로: `art-source/basic-units/v1/<id>/{front,side,back}.png`
- `<id>`는 `sword`, `spear`, `shield_unit`, `archer`, `tactician`이다.
- 납품 전 각 병종의 세 방향을 동일 축척으로 나란히 놓고 체격·그립·무기 방향·가림·접지 차이를 확인한다. 다른 병종의 장비를 잘못 복사하거나 방향별로 장비를 뒤집지 않는다.

위 치수와 원본 기준은 제작 목표입니다. 실제 그림에서 어긋난 항목은 납품 전에 고치고, 미검증 상태를 완료로 표시하지 마세요.
