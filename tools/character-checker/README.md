# 캐릭터 모션 체커

저장소 루트의 `checker.bat`을 더블클릭한다. Python 3.10 이상이 필요하며 별도 패키지 설치나 PowerShell 실행 정책 변경은 필요 없다. macOS/Linux에서는 저장소 루트에서 `python3 tools/character-checker/build.py --open`을 실행한다.

최신 자산 ZIP에서 49명 3방향 원화 147장과 조운의 승인 모션 33장을 읽어 ZIP·PNG·manifest SHA-256 및 256×256 RGBA 규격을 검증한다. 조운은 정면 숨쉬기 9장(150ms), 정면·왼쪽·후면 이동 각 8장(120ms)이다. 검색, 세력/모션 필터, 방향 비교, 재생/정지, 이전/다음 프레임, 프레임 슬라이더, 배속, 밝은/어두운 배경을 지원한다. 1:1 표시를 기본으로 하고 2배 확대도 모든 원화에 동일하게 적용한다. 공통 기준점은 (128,224)다. 다른 장수는 정지 원화만 표시한다.

결과는 `test-artifacts/character-checker/samto-character-motion-checker.html`이다. 이미지를 내장한 단일 HTML이므로 복사한 뒤 인터넷·서버·Python 없이 브라우저로 열 수 있다. 같은 위치의 `.verification.json`에는 파일별 해시와 수량이 기록된다. 결과 파일은 Git 제외이며 원본 PNG를 중복 커밋하지 않는다. 실패 시 콘솔에 원인을 남기고 배치 창이 닫히지 않으며, 브라우저의 이미지/재생 오류는 화면에 표시한다.

원화 전체의 사용자 최종 검수와 실제 게임 연결은 별도다. 조운 정면 이동의 승인 당시 미세한 눈·눈썹 변화도 원본 그대로 보인다. 이 도구는 게임·저장·기존 갤러리·런처·원본 자산을 수정하지 않는다. 8×8 전투 배치 검수 화면은 아니다.
