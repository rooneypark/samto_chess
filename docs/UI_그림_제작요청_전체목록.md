## 공통 규격

- 투명 배경 PNG, 안티에일리어싱 없음, 짙은 남색(#141C2A) 외곽선, 한 장 16색 이내.
- 글자를 넣지 않는다(세력 문장의 한자만 예외). 그림자를 그리지 않는다.
- 아이콘은 **96×96**으로 그린다. 화면에는 24~40px로 줄어 보이므로 굵고 단순한 실루엣이어야 한다.
- 이미 파일명이 정해진 것(A~F)은 **같은 이름·같은 크기로 덮어쓰면** 코드 수정 없이 바뀐다.
- 넣은 뒤: `python tools/asset_packs.py pack` → `verify` → `publish` → `git push`.

## I. 그림 한 장짜리 버튼의 빈 틀 (3장)

아래 버튼들은 글자가 그림에 박혀 있어 문구를 바꾸거나 크기를 조정할 수 없다. 글자 없는 빈 틀로 다시 받으면 A의 버튼 틀과 같은 방식으로 쓸 수 있다.

| 지금 그림 | 쓰는 곳 | 요청 |
|---|---|---|
| `ui-common/battle-start.png`, `gate-depart.png` | 전투 시작, 출정 | A의 `green-rich.png`가 오면 대체 가능. **교차한 검 아이콘만 따로** 96×96으로 (`icon-swords.png`) |
| `ui-common/battle-summon.png` | 소환 | 은화 아이콘만 따로 96×96으로 (`icon-silver.png`) |
| 병영의 훈련·각성·편성 | 병영 성장 버튼 | 세 버튼용 아이콘 96×96 (`icon-train.png`, `icon-awaken.png`, `icon-formation.png`). 틀은 A를 쓴다 |

수량은 아이콘 5개지만 "빈 틀 3종을 대체"하는 묶음이라 3으로 셌다.

## 그리는 순서 제안

1. **A 버튼 틀 2장** — 거의 모든 화면이 한 번에 바뀐다.
2. **D 세력 문장 4개, C 보상 아이콘 7개** — 여러 화면에서 반복해 쓰인다.
3. **B 기능 타일 14개, E 상품 9개** — 지금 한글 한 자짜리 임시본이 가장 눈에 띄는 곳이다.
4. **G의 게이지·카드 테두리·도장** — 병영·임무·내정의 완성도.
5. **H** — 임무 종류, 전법 효과, 역할, 전장 규칙 순.
6. **F, I, J** — 마지막.
