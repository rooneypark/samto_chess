# 모션 뼈대 좌표 제작 가이드 (PixelLab skeleton v3)

2026-11-17 · 장비 왼쪽 기본 공격 시험 3회(12회분)에서 확인한 것만 적는다. 추측은 "미확인"으로 표시한다.

**이 문서의 위치:** 무엇을 연기할지는 `캐릭터_원화_모션_스킬이펙트_통합가이드.md` 12절(장수별 자세 순서·금지 사항·타이밍)이 정한다. 이 문서는 그 문장을 **좌표로 옮겨 PixelLab에 넣는 방법**이다. 두 문서를 함께 쓴다.

## 1. 왜 좌표인가

`animate-with-text-v3`(원화 + 글)는 공격의 핵심 자세가 입력에 없어서 PixelLab이 동작을 지어낸다. 창이 눕거나, 날이 양끝에 생기거나, 찌르기가 휘두르기로 바뀐다. `animate-with-skeleton-v3`는 프레임마다 관절 좌표를 받으므로 무기 궤적이 좌표로 고정된다. 세 번의 시험에서 창의 방향·길이·끝점은 지정값과 2~5px 안에서 일치했다.

## 2. 절차

1. **뼈대 추정** — `POST /v2/estimate-custom-skeleton`에 해당 방향 원화 1장, 겉모습 설명, 동작 이름을 보낸다(1회분). 몸 관절과 함께 무기 관절(창이면 뒤끝·중간·목·날 중간·날 끝)이 자동으로 나온다. 결과의 `rig`와 `frames[0]`을 그대로 쓴다.
2. **좌표 계산** — 핵심 자세 몇 개를 숫자로 정하고 그 사이를 잇는다(4절). 손으로 점을 찍지 않는다.
3. **호출 전 검사** — 손·발이 지정 위치에 닿는지, 무기 길이가 일정한지, 모든 관절이 캔버스 안인지 계산으로 확인한다. 뼈대 미리보기를 사용자에게 먼저 보인다.
4. **생성** — `POST /v2/animate-with-skeleton-v3`에 원화, 원화의 뼈대(`first_frame_keypoints`), 프레임별 뼈대(`keypoints`), `rig`를 보낸다. 12프레임 = 3회분, 2~3분.
5. **검수** — 프레임을 눈으로 보고, 발 바닥선·반투명 픽셀·색 수를 수치로 확인한다. 깨진 프레임은 재생 목록에서 빼거나 인접 프레임으로 대체한다.

도구: `tools/pixellab_client.py`(호출), `tools/motion_trial_zhangfei.py`(장비 예시). 토큰은 환경 변수 `PIXELLAB_API_KEY`에서만 읽는다.

## 3. 반드시 지킬 것 (시험에서 확인)

| 규칙 | 근거 |
|---|---|
| **항상 전체 동작을 한 번에 뽑는다.** 핵심 자세 1프레임만 뽑지 않는다 | 1프레임 요청은 원화와 섞인 흐린 그림이 나왔다(1차). 연속 움직임을 그리는 모델이다 |
| **두 손을 양 어깨 바로 밑에 두지 않는다.** 앞손은 몸 앞으로 뻗고 뒷손은 골반 옆에 둔다 | 어깨 밑에 두면 몸이 카메라 쪽으로 돌아 "봉을 든 정면 자세"가 된다(1차) |
| **어깨 벌림은 원화의 70%**(동작 구간) | 2·3차에서 옆모습 유지 |
| **무기 관절은 한 직선 위, 길이 고정**, 손은 무기 위의 점으로 계산 | 무기 변형·이중 날 0건 |
| **원화를 캔버스 안에서 옮겨 공간을 만든다.** 옮긴 만큼 pivot이 바뀐다 | 160px 창은 pivot 128로는 앞으로 뻗을 수 없다. 장비 측면 공격은 46px 이동, pivot (174,224) |
| **멈춤(hold)은 좌표로 요청하지 않는다.** 앞 프레임을 재생에서 반복한다 | 직전 프레임과 거의 같은 좌표를 준 5번이 깨졌다(3차) |
| **한 프레임에 무기가 크게 회전하지 않게 한다** | 수평→대각선으로 한 번에 돈 10번에서 창날이 번졌다(2·3차 모두 회수 첫 프레임) |
| **마지막 프레임은 원화 자세로 돌아온다** | 대기와 이어 붙일 수 있다 |
| 깊이값(`depth`)은 생략, `z_index`는 추정값 그대로 | 생략한 상태로 앞뒤 팔이 맞게 나왔다 |

미확인: 정면·후면 방향, 기마 장수, 창 이외의 무기, 한 프레임 직선 이동의 한계(43px는 통과).

## 4. 좌표를 만드는 법

핵심 자세마다 아래 값만 정한다. 나머지 관절은 계산한다.

| 값 | 뜻 |
|---|---|
| `pelvis` | 골반의 이동(원화 기준 px). 체중 이동과 낮춤 |
| `lean` | 상체 숙임 각도. 앞으로 +, 뒤로 − |
| `angle` | 무기가 가리키는 방향. 90 = 위, 180 = 왼쪽 |
| `grip` | 앞손의 화면 좌표 |
| `near`, `far` | 각 손이 무기 뒤끝에서 떨어진 거리. 값을 바꾸면 무기가 손 안에서 미끄러진다 |
| `near_foot`, `far_foot` | 발의 이동. y를 음수로 주면 뒤꿈치가 들린다 |
| `spread` | 어깨 벌림 비율 |

- 팔꿈치·무릎은 원화에서 잰 뼈 길이로 두 마디 역운동학(IK)을 푼다. 뼈 길이를 바꾸지 않는다.
- 상체 관절(가슴·목·머리·어깨)은 원화의 골반 기준 위치를 `lean`만큼 회전한다.
- 늘어지는 부분(머리띠 등)은 골반의 가로 속도 반대 방향으로 밀고 한 프레임 늦게 돌아오게 한다.

### 역동성 (2차 → 3차에서 바꾼 것)

- **높이**: 찌르기는 허리선. 장비는 목 130 / 가슴 142 / 골반 165에서 통로 y=164.
- **속도 차이**: 당김 4프레임(느리게) → 찌르기 2프레임 → 버팀 → 회수. 자세 사이를 같은 속도로 잇지 않는다.
- **당김을 크게**: 상체 −13°, 골반을 뒤로 13px·아래로 10px.
- **무기를 미끄러뜨린다**: 당길 때 앞손은 뒤끝에서 77px, 찌를 때 56px. 몸을 더 움직이지 않고 창끝 이동이 38px → 70px.
- **끝점 넘김**: 끝점보다 5px 더 나갔다가 돌아온다.
- **하체**: 앞발 34px 내딛기, 골반 11px 낮춤, 뒷발 뒤꿈치 4~6px 들기.
- **재생 시간을 다르게**: 당김 110~130ms, 멈춤 160ms, 찌르기 50ms, 버팀 180ms, 회수 90~140ms.

## 6. 다음 장수에 적용할 때

1. 통합가이드 12절에서 그 장수의 자세 순서와 금지 사항을 읽는다.
2. 뼈대를 추정하고 원화의 목·가슴·골반 높이, 팔 길이, 무기 길이를 잰다.
3. 4절의 값으로 핵심 자세를 정한다. 무기 높이·당김·끝점은 그 장수의 체격에 맞춰 다시 잡는다(장비의 숫자를 그대로 쓰지 않는다).
4. 3절의 규칙을 지켰는지 확인하고 미리보기를 보인 뒤 생성한다.
5. 결과와 새로 알게 된 것을 이 문서 3절·5절에 추가한다.
