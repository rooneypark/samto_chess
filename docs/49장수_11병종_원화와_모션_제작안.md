이번 원화의 체격 기본안은 0.8절 방법 1이다. 머리·키·관절 위치를 고정하고 일부 장수만 어깨 폭 최대 +15%, 몸통·팔다리 두께 최대 +20~25% 안에서 조절한다. 수치는 상한이며 무기와 몸이 겹치면 폭을 줄인다. 키를 바꾸는 예외와 재빌드는 별도 결정이다.

| 마초 | 사자투구의 넓은 이마 장식과 은갑, 단단한 말 가슴 실루엣. | **서량철기** — 엔진의 최원거리 적과 실제 진입·도착 방향을 먼저 확인 → 창을 말 목 옆 수평으로 낮추고 기수는 크게 숙이며 말이 뒷다리에 힘을 모음 → `travelStart`에서 말의 다리 접지·흉곽 리듬이 보이는 질주 루프와 고정된 창 통로 |
| 공손찬 | 백마와 간결한 기병 갑주, 길고 맑게 드러나는 창대. | **백마의종** — 엔진이 고른 가장 먼 적과 도착 칸에서의 공격축을 먼저 고정한다 → 말의 뒷다리가 눌리고 기수는 안장에 붙어 크게 숙인 채 말 목 옆으로 창을 낮춘다 → 제자리 진입 자세에서 `travelStart` |

## 기마 월도·화극 · 3명

오른손이 자루 아래쪽(끝에서 55px)을 길게 잡아 세운다. 왼손은 고삐. 무기는 말 오른쪽에 둔다. 이동·대표 동작은 속보와 양손 대각 내려베기다.

| 장수 | 원화에서 살릴 특징 | 고유 전법의 동작 방향 |
|---|---|---|
| 관우 | 녹포 위 긴 검은 수염과 청룡월도의 큰 날, 갈색 말. | **청룡참** — 전방 판정 중심 칸을 먼저 표시 → 말이 뒷다리로 버텨 앞발 둘을 들고 기수는 안장을 따라 크게 올라가 머리 위까지 월도를 당김 → 앞발 착지와 동시에 골반·가슴이 앞으로 크게 접히며 월도를 표적 아래쪽을 향해 힘껏 내려찍음 |
| 장료 | 절제된 기마 갑주와 월도. 긴 수염 대신 투구와 어깨선에 중심을 둔다. | **급습** — 엔진 후열 표적과 도착 칸을 정함 → 월도를 말 옆 낮게 깊이 빼고 기수가 가슴을 숙임 → 말 뒷다리에 힘을 실은 진입 자세 |
| 여포 | 긴 투구 깃과 방천화극의 옆날, 기수의 넓은 어깨. | **무쌍** — 기존 전법의 범위와 중심을 표시 → 양손으로 화극을 크게 뒤로 빼고 말은 무게중심을 낮춰 버팀 → 기수의 골반·가슴·어깨를 반대로 풀어 화극을 전방 범위에 넓게 한 번 수평 휩쓸기 |

## 창·방패 · 2명

왼팔의 방패를 몸 앞에 세운다. 오른손은 창을 허리 옆에서 42°로 세워 창날이 어깨 위로 보이게 든다. 창은 방패 오른쪽 가장자리 밖에 둔다. 이동·대표 동작은 전투 달리기와 방패 바깥 직창다.

| 장수 | 원화에서 살릴 특징 | 고유 전법의 동작 방향 |
|---|---|---|
| 의용보병 | 단순한 병사 투구와 방패 중심쇠, 방패 밖의 짧고 명료한 창촉. | **굳건한 방어** — 보호 대상은 자신의 칸이다. 방패를 옆에서 몸 정면으로 당기며 양발 간격을 넓힘 → 무릎과 골반을 확실히 낮추고 창을 몸 옆 바깥에 세움 → 흉곽을 방패에 싣고 방패 면을 앞쪽에 단단히 세워 보호막을 발동 |
| 조홍 | 푸른 갑주와 금테 방패, 방패 밖에 선 창. 방패 안쪽은 넓은 단색 면. | **사수** — 방호 기준은 자신 칸이다. 방패를 옆에서 정면으로 크게 끌고 양발을 넓혀 골반을 낮춤 → 무릎을 깊게 굽혀 방패 뒤로 흉곽을 접고 창을 몸 옆 안전한 위치에 세움 → 앞발에 무게를 싣고 방패를 단단히 세워 방호 발동 |

## 중무기 · 2명

두 손으로 잡는다. 왼손이 자루 끝, 오른손이 머리 쪽이다. 몸 앞에서 오른 어깨 쪽으로 세워 든다. 이동·대표 동작은 무거운 뜀과 두 손 내려찍기다.

| 장수 | 원화에서 살릴 특징 | 고유 전법의 동작 방향 |
|---|---|---|
| 허저 | 흰 털깃·남색 갑옷·짧은 철퇴. 낮고 묵직한 허리와 하체를 강조한다. | **호치** — 보호·강화 대상은 자신의 칸이다. 철퇴를 가슴 앞으로 무겁게 끌어와 양발을 넓힘 → 골반을 깊게 낮추고 어깨를 닫아 압축 → 다리로 지면을 밀며 철퇴를 몸 바깥으로 벌리고 가슴을 크게 펴 강화 발동 |
| 서황 | 큰 도끼날의 넓은 면과 긴 자루, 자루를 받치는 두 팔의 간격. | **대부 강타** — 현재 적의 타격점을 먼저 고정 → 도끼를 가슴 앞에서 머리 위까지 길게 들어 올리고 무릎을 깊게 접어 무게를 모음 → 앞발을 단단히 박고 골반을 낮추며 흉곽과 양팔을 크게 접어 수직에 가까운 내려찍기로 표적을 한 번 맞힘 |

## 소품이 다른 장수의 대기 그립

아래 명단은 중복 없이 19명이다. 나머지 30명은 표의 식별점과 유형 기본 그립으로 착수한다. 이 분류는 원화 작업용이다.

## 모션에 입히기 전 확인

감녕은 낫으로 짧게 걸어 베는 기존 연기와 공통 사슬 후려치기 중 어느 쪽을 평타로 쓸지 결정해야 한다. 큰 칼 5명은 칼 폭과 자루 길이, 허저·서황은 양손 사이 간격, 원소는 지휘창, 태사자는 보조 무기의 거치 위치를 각각 확인한다. 책사의 죽간·홀·지팡이·횃불·두루마리는 실제 소품에 맞춰 그립과 시전 키 자세를 검토한다.

첫 검토는 유형별 대표 11명의 3방향을 같은 축척에서 나란히 본다. 손이 무기에 붙는지, 옆모습의 몸통 두께와 가림이 맞는지, 뒤에서도 같은 발에 무게가 실리는지 확인한다. 이후 같은 유형 안에서 장수를 나란히 놓고 얼굴·복식·무기만으로 구분되는지 360px·390px 전투판에서 확인한다. 2026-11-18 최신 기준: 새 장수 49명의 8×8 인게임 공통 표시 배율은 1.00이다(원화 1px = 칸 너비 ÷ 100). 256×256은 원화 캔버스다. 체격은 표준 본(보병 선 키 124px, 책사 111px, 기마 전체 163px), 접지는 (128,224)로 맞춘다. 무기·관모를 포함한 외곽 높이로 인물을 확대하지 않는다. 요화는 앞선 3방향 시안(v5)의 굵은 외곽선, 간결한 얼굴, 넓은 색면과 명암 밀도를 유지하며 v6의 216px 확대·세밀한 묘사는 기준에서 제외한다. 격자 밖으로 일부 나오는 외곽은 자르지 않는다. 기존 0.80 비교판은 과거 시안이다.
