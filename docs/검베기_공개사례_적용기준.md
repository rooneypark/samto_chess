# 검 베기 공개 사례와 요화 적용 기준

확인일:2026-11-16. 공개 제작자 설명/커뮤니티 제작 사례를 근거로 정리. 일반 픽셀 애니메이션 사례를 PixelLab256 정면 생성 성공으로 오인하지 않는다. GIF 링크는 확인했으나 웹 읽기 도구의 image/gif 제한으로 실제 전체 프레임을 직접 판독했다고 주장하지 않는다.

후속 사용자 지정: **SLYNYRD Pixelblog56의Sword를 요화3방향 공통 참고로 선택했다.** 공개 GIF의1024×1024 안내판을 별도로 열어 하단6단계 자세표와8방향 배치를 확인했다. 원본캐릭터/스프라이트를게임자산으로복사하지않고 칼날통과·몸통반응·중립잔상·짧은회수 구조만요화에적용한다.90GIF프레임 전체의 시각검증을 했다는 뜻은 아니다.

- 기준 박자: 준비100ms, 베기 잔상3장각50ms, 잔상 없는끝점100ms, 회수50ms, 합계400ms. 미리보기 반복대기는별도.
- 요화 측면은 채택한베기중간2장을유지하고 끝점을150ms로두어같은400ms에맞춘다. 모든방향에임의중복중간그림을만들어6장을강제하지않는다.
- 후면회수는 손을어깨위로들지않고몸가까이당기는1장중간자세로연결한다. 정면중간은몸앞의대각통과와칼날을따르는잔상을재생성한다.

## 확인한 1차 출처

1. SLYNYRD, Pixelblog56: https://www.slynyrd.com/blog/2025/5/23/pixelblog-56-top-down-character-attack-animation
   - 제작자가8방향 검 베기를 공개. 같은 손을 유지하며 준비/빠른궤적/끝점/회수를 분리한다. 검 예시는100,50,50,50,100,50ms의6프레임400ms. 끝점은 잔상 없이 잠시 보여주고 회수는 대기 중간자세로 짧게 연결한다. 준비·회수에 잔상을 넣으면 실제 타격 동작이 흐려진다고 설명.
2. imonk, itch.io Sword Slash Animation: https://itch.io/t/2489691/pixel-tutorial-sword-slash-animation
   - 제작자 본인의 대각베기 단계별 이미지/GIF와 완성 예시. 검을 뒤로 모을 때 상체를 조금 비틀고, 베면서 반대로 회전하며 체중을 싣는다. 회수는1장 중간자세로도 연결 가능. 요화에는 방패와 푸른색 효과를 가져오지 않고 동작 구조만 참고한다.
3. r/PixelArt 제작자 공유: https://www.reddit.com/r/PixelArt/comments/1nngrmr/slash_animation_tips_i_learned_while_making_it/
   - 작성자의 베기 경험: 몸/다리 체중 이동, 시작과끝의 연결, 잔상 점진소멸, 빠른평타의 반응성. 이 글의 피해판정 확대 제안은 우리게임에 적용하지 않는다.
4. PixelLab 실제 공개 비교 실험: https://github.com/Shilo/pixellab-pip/blob/main/docs/pixellab/pixellab-pixminimax-vs-v3-animation-spike.md
   - sword/bow 등 제한된 테스트에서 PixMiniMax가 준비·동작·회수 구분이 더 뚜렷했다고 보고하나 끝자세 준수는v3가 더 정확했고 검잔상이과장되는 문제도 명시한다. 요화256정면과 동일조건 성공증거는 아니다. 이것만으로 엔진을바꾸거나 성공보장하지 않는다.

## 요화에 적용할 수정 판정 — 출처를 바탕으로 한 작업 판단

- 정면: 잔상만 머리위에서 돌고 검신은옆으로이동하는 프레임을 쓰지 않는다. 어깨→팔꿈치→손목→칼끝이 실제 오른쪽위에서왼쪽아래로 넘어가는 통과자세가 필요하다. 칼날바로뒤에 흰/은색잔상이붙어야한다.
- 박자: 준비보다 실제칼날통과가빠르고, 완전히내려벤끝점을짧게보여준다. 균등속도로모든중간프레임을연결하지않는다. 위400ms는참고예시이며 게임공격주기/피해판정은변경하지않는다.
- 후면: 승인된베기구간은유지. 끝점에서손을몸가까이당겨원래세운대기로곧바로돌아온다. 머리위로검을높이들어재장전하는중간프레임은제외/재생성한다. 준비자세역순은이문제를재현할수있으므로기계적으로사용하지않는다.
- 측면: 현재동작유지. 유색/마법이아닌짧은중립베기잔상은허용. 체격/윤곽/색·손역할·단일검규칙은그대로다.
- 두끝점보간만으로실제베기궤적이보장되지않는다. 필요하면칼날이몸앞을대각으로통과하는핵심중간자세를추가하고, 사례의준비/타격/끝점/회수구조에맞춰선별한다.
