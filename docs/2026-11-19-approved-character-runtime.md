# 확정 원화 인게임 적용 · 2026-11-19

사용자 요청으로 11월 18일 확정된 49장수·147방향 원화를 모든 인게임 정지 표시에 적용했다. 초상화는 확정된 `game/assets/portraits-v4/` 49종을 유지한다. 원화 승인·정지 이미지 적용과 모션 완성은 구분한다.

## 공용 연결

- 정본은 `art-source/characters/v1/<id>/{front,side,back}.png`. 복사본을 만들지 않는다.
- `game/character-art-data.js`는 정본 manifest에서 만든 49명 메타데이터다. 갱신 명령은 `node game/tools/build-character-art.mjs`.
- `game/character-art.js`를 병영·성문·상점·동맹·군웅대전·도감·편성·파견·선택/등용 결과·전투 결과/기록 및 전투 정지 표시에서 공유한다. `heroes.js`의 전신 fallback도 같은 정본이다.
- 공통 논리 캔버스 256×256, 접지 (128,224). 장비 1254px 원본은 변경하지 않고 표시 좌표만 논리 크기로 변환한다. 전투 캔버스 렌더도 원본 전체를 256 논리 크기로 그린다.
- 이전 장수별 70%/85% 추가 보정은 제거했다. 체격과 말 비율은 확정 픽셀에 담긴 차이를 그대로 사용한다. UI 영역마다 공통 배율을 적용하며 무기 외곽으로 장수별 contain-fit하지 않는다. 전투판은 표시 배율 1.00이다.
- 메타데이터의 visible은 alpha>16인 육안 외곽으로 측정한다. 알파가 낮은 픽셀을 포함한 원본 PNG는 모두 해시 그대로 보존한다.

## 장식용 무작위 표시

- 성문은 실제 편성, 병영은 실제 보유 목록과 선택 장수를 표시한다.
- 일반 등용 상점은 6개 서로 다른 전투 병종에서 1명씩, 동맹 장식은 서로 다른 2개 병종에서 1명씩 무작위로 표시한다. 명단은 49명 전체이며 소유 여부를 변경하지 않는다.
- 같은 화면의 재화 선택·출석 등으로 재렌더해도 장식 명단은 유지한다. 화면을 나갔다 들어오면 다시 뽑는다. 저장에는 기록하지 않는다.
- 픽업 대상, 실제 대전 상대/편성, 도감 선택, 파견 부대, 등용 결과 및 전투 결과/기록은 실제 정보를 유지한다.
- 기존 카드 공개 및 전법 직전 컷인 연출은 유지한다. 이후 사용자 요청으로 추가 여섯 종류의 순간 연출도 적용했다. `docs/2026-11-19-scene-motion.md` 참고.

## 구본 제거와 복구

- `game/assets/`의 구형 전신 18장, idle 14장, 전투용 정지 8장, 성문 정지 6장, 구 장수가 합성된 상점 배경 등 2장: 총 48개 제거.
- 상점은 기존 장수 없는 `pickup-hall-v3.png` 배경에 확정 독립 원화를 올린다.
- 제거 목록은 `asset-packs/retired-character-stills.json`. 해당 로컬 ZIP만 재구성하고 catalog에서 48개를 제거했다. 진행 중인 다른 모션/가이드를 새로 패키징하지 않았다.
- `asset_packs.py pack`은 제거 목록을 제외하므로 과거 UI 생성기가 만든 구본도 재납품하지 않는다. restore는 현재 catalog만 복구한다.
- 과거 UI 제작 원본과 일반 적 병사의 기존 모션은 보존한다. 새로운 장수 모션을 완성한 것으로 취급하지 않는다.
- 커밋·푸시·릴리스 업로드는 수행하지 않았다. 로컬 ZIP/catalog 변경은 후속 업로드 때 함께 게시해야 한다.
