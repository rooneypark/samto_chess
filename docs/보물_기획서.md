# 삼국체스 보물 기획서 v1 — 명검·명마·병서·기물 100종

2026-11-14 · 제작용 확장 시안 목록 · 게임 데이터/밸런스 적용 전

## 1. 개편 방향

기존 흑철 호심경·백마 인장·청룡 병서 등12종 중심의 제작 계획을 **삼국지에서 알아볼 수 있는 보물 중심**으로 바꾼다. 의천검·청공검·청룡언월도·방천화극·적토마·손자병법·옥새가 수집의 중심이다. 무기·명마는 이름만 다른 인장으로 그리지 않고 실제 물건/말의 모습으로 제작한다.

아래100종은 이름 중복을 정리한 **시안 제작 후보 전체 목록**이다. 전부 역사상 실재한 삼국시대 유물이나 모든 삼국지 게임의 공통 보물이라는 뜻은 아니다. 삼국지 대표 보물, 조조전 계열 판타지 장비, 다른 시대의 고전·명품을 구분한다. P1 핵심32종 → P2 확장 → P3 고전/기물 순서로 제작한다. 효과 역할과 외형은 삼국체스용 신규 제안이며 코에이의 능력치·이미지를 그대로 옮기지 않는다.

장수당 보물1개, C/B/A/S, 1~5성, 잠금/즐겨찾기/장착 보호 원칙을 유지한다. 무기·갑옷·말이라는 분류는 도감 필터이며 장착 슬롯을 추가하는 뜻이 아니다. 명마 장착이 승인된 캐릭터의 말을 자동 교체하거나 보행 장수를 기마로 바꾸지는 않는다.

태평요술서는 [연의1회](https://zh.wikisource.org/zh-hant/%E4%B8%89%E5%9C%8B%E6%BC%94%E7%BE%A9/%E7%AC%AC001%E5%9B%9E), 둔갑천서는 [연의68회](https://zh.wikisource.org/wiki/%E4%B8%89%E5%9C%8B%E6%BC%94%E7%BE%A9/%E7%AC%AC068%E5%9B%9E)의 소설적 도술 계열로 취급한다. R14 자료에서 데이터만 존재하는 항목을 일반 플레이 등장 보물로 잘못 표기하지 않도록, 이 두 항목의 게임 근거는 CC로 기록한다.

## 3. 제작 목록100종

## 4. 게임 효과와 성장 설계

### 유지할 기반

- 한 장수에 한 개. 동일 보물의 개별 인스턴스ID를 유지한다.
- C/B/A/S와 별1~5는 별도 축이다. 강화로 보물 이름이나 그림이 바뀌지 않는다.
- 현재 별당 기본 효과 배율은 `1 + 0.25 × (별-1)`이다. 동일1성 재료 수2/4/8/16과 현재 등급별 골드 계산을 임의 변경하지 않는다.
- 장착·잠금·즐겨찾기 보물을 재료로 사용할 수 없고, 출정 중 변경 제한을 유지한다.

### 신규 효과 제안 원칙

처음에는 기존 엔진의 `atk/hp/def/mdef/speed/move/skill/heal/shield`로 분류별 역할을 만든다. 위100행의 역할은 이 분류에 대응한다. 같은 계열이라도 그림과 획득처를 달리하고, 이름만으로 무조건 S등급을 주지 않는다. 구체 등급/수치는 아트 제작을 막는 조건이 아니며 효과 검증 단계에서 별도 확정한다.

청공검의 방어 관통, 자웅일대검의 지원, 명마의 회피/이동 특성 같은 개성은 **추가 패시브 후보**다. 현재 단일 stat 구조에서 지원하지 않는 효과를 이미 적용된 것처럼 설명하지 않는다. 특수 효과를 추가할 때는 발동 조건·대상·쿨다운·중첩·각성/세력 상호작용·상한을 모두 정의하고 엔진 검증을 거친다. 세력 전용 장착 제한은 기본으로 만들지 않는다.

### 획득과 공급 제안

P1은 신규 도감의 대표 전시/목표 보상, P2는 지역·전역별 보상 풀, P3는 탐색/교환/장기 수집으로 구분한다. 100종을 한 모집 풀에 한꺼번에 넣어 동일 보물 강화가 어려워지게 하지 않는다. 현재 모집·교환·토벌 규칙을 유지한 상태에서 단계별 선택상자/목표 교환의 공급안을 별도로 검증한다. 확률·가격·천장·무료 수급은 이번 문서만으로 변경되지 않는다.

## 5. 이미지 생성 가이드

캐릭터와 동일한 간결한 픽셀 세계관, 짙은 외곽과 절제된 명암을 사용한다. 기존 승인 UI를 다시 그리지 않는다. 보물 원화는 **물건 자체만 독립 투명 PNG**로 제작한다.

- 권장 전달 캔버스256×256 RGBA. 외곽 최소16px 여유. 장병기는 대각선으로 배치해 전체 날과 자루를 보존한다. 종횡비를 찌그러뜨려 꽉 채우지 않는다.
- 말은 전신, 갑옷/옷은 인물 없이 물건 형태, 서적은 닫힘/펼침과 묶음 구조, 부채는 깃/잎의 실루엣으로 구분한다.
- 카드 배경·등급 색 테두리·별·이름·설명·selected/pressed·바닥 그림자·큰 발광은 원화에 넣지 않는다.
- 같은 분류의 크기와 시점을 통일한다. 3/4 시점을 기본으로 하되 평평한 무기/부채는 가독성을 우선한다. 보물은 한 방향 시안이며 캐릭터의 3방향을 요구하지 않는다.
- 상세256px뿐 아니라 축소64/32px에서도 이름 없이 서로 구분되는지 확인한다. 축소용64/32는 검수 크기이며 현재 UI의 실제 표시 크기를 강제로 바꾸지 않는다.
- 흰색·검정·대조색에서 검수한다. 외곽선·금색 장식·흰 깃털을 배경으로 오인해 제거하지 않는다. 가짜 체크무늬 배경이 아닌 실제 alpha를 확인한다.
- 100개는 각각의 PNG와 contact sheet를 전달한다. 큰 목록 시안 한 장에서 아이콘을 잘라 납품하지 않는다.
- 파일: `art-source/treasures/v1/tr-001.png` 등. 이름 변경에도 ID는 유지한다. 생성 프롬프트·참고·canvas·visibleBounds·파일·검수 상태를 manifest에 남긴다.

생성 요청문:

> 삼국체스 보물 [ID/이름]의 독립 투명 픽셀 원화를 제작한다. 외형 핵심은 [목록의 외형 열]이다. 첨부된 우리 게임 캐릭터와 같은 간결한 픽셀 밀도·외곽·명암을 사용한다. 보물 전체를 온전히 보존하고 256×256 캔버스의 바깥16px는 비운다. 배경·카드·프레임·글자·등급·별·UI·바닥 그림자는 없다. 작은 아이콘에서도 실루엣과 재질이 읽혀야 한다. 다른 게임의 아이콘을 복사하거나 이미지 위에서 잘라오지 않는다.
