# 인게임 순간 연출 적용 · 2026-11-19

사용자가 제안된 여섯 종류를 모두 깔끔하게 적용하고 프리뷰를 보여 달라고 요청했다. 아래 구현은 실제 게임에 연결했으며, 사용자 시각 검토는 프리뷰 확인 대기다. 기존 카드 공개/전법 컷인과 확정 UI 틀·원화 픽셀은 유지한다.

## 적용된 순간

| 종류 | 실제 연결 | 연출 |
|---|---|---|
| 선택·편성 | 병영 선택, 편성 선택/교체/순서 변경 | 장수/초상만 3px 이하로 짧게 들렸다 복귀. 교체 슬롯은 얇은 금빛 강조. 약 180~260ms |
| 훈련·각성 | 저장 성공 뒤 현재 선택한 장수 | 증가한 능력치 강조 360ms, 새 별 안착 380ms. 실패/취소는 성공 연출 없음 |
| 보상 수령 | 사용자 조작 뒤 확정된 재화 증가 | 골드/다이아 각각 최대 3개 작은 아이콘이 상단으로 이동. 460ms + 최대 70ms 순차 지연. 일괄 수령은 90ms 동안 합쳐 표시 |
| 출정·해금 | 전역 출정 및 전투 준비 진입, 저장으로 열린 전역 첫 표시 | 선택 지점의 얇은 강조 및 낮은 불투명도 전환 260~280ms. 해금 강조 420ms |
| 합성·강한 타격 | 실제 합성 저장 성공, 실제 피해 로그 | 합성 마름모 순차 안착 최대 440ms. 타격은 대상만 최대 2px 반응. 일반 소타격과 작은 지속 피해는 제외. 방패 소진은 짧은 은색 선 |
| 승리·결과 | 실제 라운드/대전 결과 화면 | 제목 진입 260ms, 지급 완료/정상 중간 보상 카드만 순차 표시. 같은 결과 재렌더로 반복하지 않으며 저장 실패를 지급 성공처럼 강조하지 않음 |

## 공용 구현

- `game/scene-motion.js`: Web Animations API 기반 짧은 연출, pointer-events:none 장식, 정리/취소, tick 기반 전투 타격.
- `game/scene-motion-controller.js`: durable store의 저장 완료 알림에서 성장/재화/해금을 감지. 원본 저장과 전투 객체를 수정하지 않는다. 현재 설정은 알림의 캐시를 사용하므로 유닛마다 저장 전체를 복사하지 않는다.
- `game/scene-motion.css`: 소수의 색과 얇은 강조, 합성 마름모. 화면 전체 흔들림, 흰 섬광, 반복 입자, 대기 연출 없음.
- 연출을 기다리기 위한 입력 잠금이나 보상/판정 지연을 추가하지 않는다. 기존 트랜잭션 동안의 잠금은 유지한다.
- 게임의 움직임 줄이기·효과 줄이기 및 OS `prefers-reduced-motion`을 따른다. 설정 전환 시 진행 중인 새 연출도 취소·정리한다.
- 전투 타격은 log/tick에서 표시만 계산하므로 일시정지 시 같은 위치에 멈추며 재접속/속도 변경에도 전투 수치가 바뀌지 않는다. 사망/이동/공격 모션을 새로 생성한 것으로 취급하지 않는다.

## 프리뷰

- `game/previews/scene-motion-v1/index.html`: 여섯 장면, 종류별 재생/전체 재생/움직임 줄이기. 확정 원화와 런타임 연출 함수를 사용한다. 숫자는 예시이며 store/IndexedDB를 열거나 실제 저장을 변경하지 않는다.
- 로컬 주소: `/game/previews/scene-motion-v1/`.
- `node game/previews/scene-motion-v1/review.cjs`: 실제 브라우저 102프레임/12fps 캡처 → `test-artifacts/scene-motion/scene-motion-preview.mp4`. ffmpeg로 인코딩하며 원화를 수정하지 않는다.

## 검증

- 기본 97개 테스트 통과. 타격의 결정성·대상 한정·저장/전투 불변·줄이기 설정 포함.
- `scene-motion-browser`: 데스크톱/모바일, 여섯 장면, 프리뷰 저장 불변, 장식 입력 통과와 제거, 실제 훈련/각성 저장 성공, 실패 시 성공 연출 없음, 실제 임무 보상, OS 움직임 줄이기 통과.
- `missions-flow`, `mail-flow`, `formation-flow`, `results-flow`, `approved-motion`, `campaign-flow`, `ui-shell`, `battle-ui`, `battle-alignment`, `character-art` 통과.
- UI 위치와 원화는 애니메이션이 끝난 정지 상태에서 비교한다. 선택·성장·보상·출정·전투의 원래 상태/정산을 바꾸지 않는다.
- 사용자 프로필에 테스트 장수/재화를 넣지 않았다. 모든 실제 흐름 검증은 격리된 새 브라우저에서 수행했다.
- 커밋·푸시·릴리스 업로드는 수행하지 않았다.
